# Dados

Os dados não são redistribuídos com o projeto. Baixe o arquivo completo na página oficial da competição:

https://www.kaggle.com/competitions/home-credit-default-risk/data

No Colab, mantenha o ZIP no Google Drive e aponte `CAMINHO_ZIP` para ele. Localmente, defina `HOME_CREDIT_DATA_DIR` para uma pasta que contenha os CSVs descompactados.

A subpasta `raw_recuperados/` contém somente os sete CSVs que passaram na verificação de CRC do download truncado fornecido. Ela é ignorada pelo Git e não deve ser confundida com a base completa.
